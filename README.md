## Tech Stack

I don't really stick to one stack… I just use whatever gets the job done.
Mostly Go, Java, Python, JavaScript, and TypeScript.
For backend and web stuff I use Spring Boot, Node, NestJS, Angular, React, and Next.js.
For databases I usually go with MySQL, PostgreSQL, or MongoDB.
When things need to run properly, Docker and Kubernetes help a lot.
And lately I've been using C++ and CMake for lower-level work.

That's pretty much it.
